# DBZ Digital TCG — Alpha

[Download the Windows installer](https://github.com/JoePerry/DBZ-Digital-TCG-Downloads/releases/latest/download/DBZ-Digital-TCG-Setup.exe)

1. Run **DBZ-Digital-TCG-Setup.exe** (about 18 MB).
2. Open **DBZ Digital TCG** from your desktop or Start menu.
3. Let the launcher download the game on first launch (about 2.3 GB).

Requires 64-bit Windows 10 or 11 and an internet connection. Python is included;
you do not need to install it separately. This is early alpha software for testers.
Online features require an approved game account.

The launcher checks for updates each time you open it. It reuses unchanged download
packages, verifies downloaded files, and keeps player saves separate from game
versions. Updates wait until the previous game session has closed.

Only download **Setup** to get started. The ZIP components and `latest.json` in
Releases are used automatically by the launcher.

This repository contains release downloads and these instructions only.
The game's development source is not published here.
